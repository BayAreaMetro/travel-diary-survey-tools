# Read/Write Pipeline Steps

This module provides data input/output operations for the survey processing pipeline.

For detailed API documentation including function signatures, parameters, and algorithms, see:
[Read/Write API Documentation](https://bayareametro.github.io/travel-diary-survey-tools/pipeline_steps/read_write/)

The documentation includes:

- `load_data()` - Load canonical survey tables from files
- `write_data()` - Write canonical survey tables to output formats
